🔬 How the Hardware Was Coded & Silicon Behavior Manipulated

Unlike software code that simply instructs existing execution units, our synthesizable Verilog code physically restructured how logic gates and registers interact:

1. Decoupled Ping-Pong Weight Storage (`pe_double_buffered.v`)

In ordinary software, changing weights halts arithmetic execution while data is pulled from memory. We manipulated hardware by wiring two distinct physical 8-bit registers per PE:

// Background Shadow Register (Bank 1) captures upcoming weights without stopping math if (load_weight) shadow_weight <= weight_in; // 1-Cycle Strobe flips shadow weights into active compute registers (Bank 0) if (swap_weights) active_weight <= shadow_weight; // Multiplier draws strictly from active register acc_out <= acc_in + (a_in * active_weight);

2. Silicon-Enforced Wavefront Skewing (`systolic_array_2x2_skewed.v`)

Systolic matrix multiplication requires row inputs to arrive staggered by 1 cycle. Instead of wasting CPU instructions to pad matrices in RAM, we built an 8-bit D-Flip-Flop delay buffer directly onto Row 1:

assign a_row0_skewed = row0_data_in; // Row 0 routes immediately (0 delay) always @(posedge clk) begin // Row 1 latches into physical DFF (1-cycle delay) a_row1_skewed <= row1_data_in; end

3. Autonomous 6-State Hardware Controller (`systolic_controller.v`)

Rather than burning CPU cycles to sequence matrix loops, a dedicated Finite State Machine acts as an autonomous autopilot using only 8 flip-flops:

// Autonomous state transitions: IDLE -> LOAD_W -> SWAP_W -> STREAM -> DRAIN -> DONE case (state) S_IDLE: if (start) next_state = S_LOAD_W; S_LOAD_W: next_state = S_SWAP_W; S_SWAP_W: next_state = S_STREAM; S_STREAM: if (stream_idx == 2'd1) next_state = S_DRAIN; S_DRAIN: if (drain_cnt == 3'd3) next_state = S_DONE; S_DONE: next_state = S_IDLE; // Emits 1-cycle 'done' interrupt pulse endcase

4. In-Pipeline Combinational Re-Quantization (`requant_unit.v`)

Eliminated branching instructions (`CMP`, `JLE`) for ReLU and fixed-point scaling by evaluating non-linear clamping in pure combinational CMOS logic before latching:

assign relu_val = (acc_in > 32'sd0) ? acc_in : 32'sd0; // Pure wire multiplexer assign scaled_val = relu_val >>> SHIFT_BITS; // Arithmetic shift right // Synchronous saturating clamp to signed INT8 [0, 127] if (scaled_val > 32'sd127) data_out <= 8'sd127; else data_out <= scaled_val[7:0];
